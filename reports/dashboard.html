02 / The Model

A multi-task neural network predicts what fare and seats-remaining should look like for a flight with this route, weekday, days-to-departure, cabin, and airline — trained on the 04-16 search, scored on 04-17 (a real out-of-sample day, not a random shuffle). Route, cabin, and airline each get a learned embedding rather than one-hot encoding, feeding a shared trunk that splits into two heads trained jointly — the point being that each route's embedding has to be useful for predicting both fare and seat-pace, not fit to just one. The gap between actual and expected is the anomaly signal.

Debugged, not just built
The network trained to a perfectly flat loss and predicted the exact same number for every flight — worth tracing to ground, not retrying with different hyperparameters

First suspected a dying-ReLU collapse from mixing raw embeddings with unnormalized numeric inputs — added batch normalization throughout. No change: prediction variance was still exactly 0.0. Inspecting the actual input arrays found the real cause: totalTravelDistance was missing on ~5% of rows (a real gap in the scrape), and StandardScaler silently carried the NaN through the transform instead of raising — one NaN poisons every unit it touches once concatenated. Fixed with a median imputed from training data only, reused on test.

Once genuinely training, the honest comparison: this network reaches 32.8%/32.1% improvement over baseline, versus 54.1%/37.8% for a gradient-boosted model on the identical features and split. Reported as-is rather than tuned until it looked better — trees routinely beating neural networks on tabular data with high-cardinality categoricals at this scale is a well-documented result, not a failure of this implementation.

Two independent signals — the seats-remaining residual, and a completely separate real aircraft-capacity estimate — agree with each other on which flights are running hot or cold.

The earlier gradient-boosted model's seats-remaining explanations were dominated by one feature 94% of the time. The neural network doesn't have that problem: 60 of 60 sampled flights got a genuinely unique driver combination for both fare and seats-remaining — airline, fare type, distance, and itinerary complexity all show up as top drivers depending on the flight, not one feature swamping everything else. A real, non-obvious trade-off worth stating plainly: the tree-based model was more accurate (Section 02), the neural network's explanations are more diverse — neither property implies the other.
